# YOLO Buoy Detection

[English](README.md) | [Türkçe](README_TR.md) | [Deutsch](README_DE.md)

Computer-Vision-Toolkit für Datensatzvorbereitung, YOLO-Training und Objekterkennung von Bojen in maritimen Bildern.

## Portfolio-Fokus
- Datenbereinigung und Label-Workflows
- YOLO-Objekterkennung und Evaluation
- Bildverarbeitung für maritime Szenen
- Reproduzierbare Trainings- und Auswertungsschritte

Vor dem Training sollten Datensatzversion, Klassenverteilung, mAP50-95 und Beispielvorhersagen dokumentiert werden.
